# 🧮 Project 01 - Interactive Calculator & Unit Converter

> InternCircle Python Internship - Task 01

A simple and user-friendly Command Line Interface (CLI) Calculator built with Python.

### ✨ Features

**1. Calculator Operations**
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/) - with Zero Division handling

**2. Unit Converter**
- Kilometers to Miles - `miles = km * 0.621371`
- Celsius to Fahrenheit - `F = (C * 9/5) + 32`

**3. Input Validation**
- Handles invalid inputs (like letters instead of numbers)
- Uses `try-except` and `while` loop to keep asking until valid input
